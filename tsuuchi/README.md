# 通知(tsuuchi)

**できること**: アプリから会員に、招待、予約の確認、案内を、メールとブラウザーの通知(Web Push)、
スマホのアプリの通知(iPhone の APNs、Android の FCM)で届けます。広告は送りません。

**使う人**: 会員やお客さんに、取引の知らせを送る事業。

**決めること**: どこからメールを送るか(自分のメールサーバーか、中継のサービスか)。スマホのアプリの
通知を、自分のサーバーから直接送るか、中継のサービスを使うか。何を知らせるか。通知そのものには、
会員の情報を入れません。

**つながり**: 送る相手は [kaiin](../kaiin/)、メールのサーバーは [mail](../mail/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
