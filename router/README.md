# ルーターと記録(router)

**できること**: 会社のネットワークのルーターを選び、区画ごとに止められる形に組み、ルーターと VPN の
記録を別の機械に置きます。

**使う人**: 会社でネットワークの面倒を見る人と、会社のネットワークの仕事を受ける人。

**決めること**: 区画の分け方、外から入る人の入り方、ルーターの選び方(記録を送れる業務用の物、
OpenWrt、Linux の箱)、記録を誰が読み、どれだけ残すか。AI は答えを先に出さず、選ぶと何が変わるかを伝えます。

**つながり**: Linux の箱を境界にするなら [network](../network/)、毎日の点検は [tenken](../tenken/)、
管理者の ID と外に開いた口の点検は [ninshou](../ninshou/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
