# 鍵(kagi)

**できること**: 扉にスマートロックを付け、本人確認が済んだ人にだけ、決めた期間だけ使える鍵
(暗証番号など)を、自分のアプリから出して消します。

**使う人**: 民泊や小さな宿、事務所、貸し部屋。

**決めること**: どの錠を使い、どう動かすか(手元の機械か、各社のクラウドか)。電池切れやネットが
切れたときに、どう開けるか。

**つながり**: 鍵を出す前の本人確認は [honnin](../honnin/)、鍵の知らせは [tsuuchi](../tsuuchi/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
