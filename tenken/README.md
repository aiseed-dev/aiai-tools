# 毎日の点検(tenken)

**できること**: 毎朝、会社のネットワークの機器(ルーター、VPN の機器、スイッチ、無線の親機)に当たる弱点の
知らせ(米国 CISA の悪用された弱点の一覧と JVN)が出ていないかと、機器の記録が記録の機械に届いているかを、
出典を付けて 1 つの知らせにします。何も無ければ 1 行です。AI は読んで書くだけで、機器には何もしません。

**使う人**: 会社でネットワークの面倒を見る人と、その仕事を受けた人。

**決めること**: 機器の一覧(`kiki.csv`)、知らせの受け方(ファイルかメール)、AI を使うか(Gemini、手元の
Ollama、使わない)。

**つながり**: 記録の機械は [router](../router/) の手引きで作ります。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。使い方は [利用者マニュアル](docs/manual.adoc)、
作りは [設計書](docs/design.adoc)、確かめ方は [試験の手順](docs/test.adoc) にあります。
