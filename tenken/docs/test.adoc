= 毎日の点検(tenken)試験の手順

== 自動の試験

ネットにつながず、決まった知らせ(CISA と JVN の見本)で確かめます。

----
python3 tenken/test_tenken.py
----

確かめること:

* 静かな日は 1 行になる
* メーカーと製品の名前は、大文字と小文字、空白、記号に関わらず当たる。空の名前は当たらない。似た名前の別の
  製品(FortiGate と FortiOS)は当たらない
* 前から載っている物は、初めの日に 1 度だけ並べ、次の日からは件数だけになる
* 知らせた物は、次の日に「新しい」にならない
* 止まった記録と、無い記録を見分ける
* 知らせが取れなかった日は、1 行にならない
* AI は静かな日には呼ばれず、所見は 8 行に切られる
* JVN は日本語のメーカーの名前で当たり、CISA にある CVE は 2 度知らせない。3 つの期間が全部 `n` になっている
* 列の足りない一覧では止まる

試験が気づくかも確かめました(2026-10-16): JVN の重ねの除き、日本語の名前の扱い、期間の指定、記録の時刻、
新しい物の分け方、所見の 8 行の切り方を、それぞれ壊すと、試験が失敗します。

== 本物の知らせで確かめる

記録の機械で、見本の一覧(`kiki.csv.example`)を使って 1 度動かし、次を見ます。

. CISA と JVN から取れ、「取れなかった知らせ」が出ないこと
. 当たった知らせに、CVE か JVN の番号と、出典の URL が付いていること
. 次の朝、同じ物が件数だけになること
. 記録のファイルの機器を 1 台止めると、次の朝「届いていない」になること
