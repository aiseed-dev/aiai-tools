# 見守り(kanshi)

**できること**: 住宅、空き家、集合住宅の共用玄関を、カメラと、画像を読んで言葉で説明する AI(VLM)で
見守ります。要れば顔認識を加えます。出来事を言葉で残し、持ち主に知らせます。

**使う人**: 自分の家や空き家を見守りたい人。空き家の管理や、集合住宅の管理を仕事にする会社。

**決めること**: どこを映すか。顔認識を使うか。録画を残す期間。仕事で使うなら、掲示と公表、
管理組合の決議。

**つながり**: 鍵の記録は [kagi](../kagi/)、ネットワークは [network](../network/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
