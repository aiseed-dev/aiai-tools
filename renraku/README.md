# メッセージ(renraku)

**できること**: アプリに、会社と会員のやりとり(問い合わせ、連絡)を入れます。

**使う人**: 会員やお客さんと、アプリの中でやりとりしたい事業。

**決めること**: 会員どうしのメッセージを入れるか。入れるなら、要る届出などを、AI に関係する法令を
調べさせて確かめます。ブロックと通報の決まり。残す期間。

**運営が読んでよいもの**: 会員どうしのメッセージは、通信の秘密で守られます。運営が見るのは、
受け取った人が通報で送ってきた文だけにします。

**つながり**: 会員は [kaiin](../kaiin/)、新しいメッセージの知らせは [tsuuchi](../tsuuchi/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
