# 会員(kaiin)

**できること**: アプリで会員を集めて預かります。招待、Apple か Google でのサインイン、版を付けた
同意、本人が自分の記録を見て消せること、係の人には数だけ見せることを作ります。

**使う人**: 会員制のサービス(相談、コミュニティ、教室など)、民泊の宿泊者を受ける事業。例は、
aiai の会員と、民泊の宿泊者です。

**決めること**: 何を預かるか。同意の文。残す期間と、退会したときの扱い。係の人を誰にするか。

**つながり**: サインインは [ninshou](../ninshou/)、知らせは [tsuuchi](../tsuuchi/)、やりとりは
[renraku](../renraku/)、見たページの記録は [kaiseki](../kaiseki/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
