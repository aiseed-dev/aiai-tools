# 認証(ninshou)

**できること**: 社員とお客さんのサインインを、PocketBase に集めます。自分で作るアプリは、みな
PocketBase で「誰か」を確かめます。

**使う人**: 自分のアプリを作る会社や団体。社員は Apple ID か Google ID で入ります。

**分かれていること**: 前半(手順と「会員のサインイン」)が PocketBase の認証です。「管理できる人が
いるか」と「点検する」は、その前に確かめる、会社全体の守りの話です。管理者の ID、ドメインと DNS、
外に開いている口、社内の区画の分け方を見ます。

**決めること**: 誰が管理者の ID を持つか。社員のサインインに何を使うか。点検の間隔。

**つながり**: [kaiin](../kaiin/)(会員)、[honnin](../honnin/)(本人確認)、[api](../api/) の前に置きます。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
