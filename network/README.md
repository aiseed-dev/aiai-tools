# ネットワーク(network)

**できること**: 会社や事務所、民泊の建物のネットワークを、ルーターを買わずに、Linux の PC 1 台で
組みます。ファイアウォール、Wi-Fi、VPN(外から社内に入る道)も作ります。

**使う人**: 事務所や建物のネットワークを、自分で持ちたい会社や人。

**決めること**: 回線の方式に合わせた置き方(ホームゲートウェイの後ろか、すぐ後か)。社内をどう分けるか。

**つながり**: 見守りのカメラは [kanshi](../kanshi/)、サーバーは [server](../server/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。
