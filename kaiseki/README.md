# 解析(kaiseki)

**できること**: 自分のサイトで、どのページがどれだけ読まれたかを、自分のサーバーで数えます。
Google Analytics の代わりです。受け入れた人の分は、会員とひもづけて、その人に合った案内に使えます。

**使う人**: 自分のサイトやアプリを持つ事業。天気のサイト(weather.time-j.net)と aiai で使っています。

**決めること**: どのサイトで数えるか。受け入れるかを聞くか(聞かずに数だけにもできます)。何に使うか。

**つながり**: 会員は [kaiin](../kaiin/)、予測は [bunseki](../bunseki/)。

**使い方**: AI に [SKILL.md](SKILL.md) を読ませて、一緒に進めます。ページに置くスクリプトは
[kaiseki.js](kaiseki.js)、受け口は [server.py](server.py) です。
